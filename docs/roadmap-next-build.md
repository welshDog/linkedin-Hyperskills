# Roadmap: next build

## Phase 1 — Make the system more intelligent

### Goals

- learn voice from examples
- store brand memory
- detect weak or unsupported claims
- improve post scoring

### Additions

- `brand_memory.json` or database layer
- voice profile generator
- claim safety rules
- scored draft review output

## Phase 2 — Build the analytics loop

### Goals

- track performance by format and topic
- identify winning structures
- suggest next content based on actual results

### Additions

- engagement logging
- post taxonomy
- A/B hook testing
- top-performing pattern extraction

## Phase 3 — Founder and operator playbooks

### Goals

- build highly tailored content modes
- support founders, agencies, B2B operators, and builders

### Additions

- founder-led content modes
- sales-driven content engine
- expertise-led content workflow
- company narrative builder

## Phase 4 — Publishing and content orchestration

### Goals

- automate sequences, not just isolated posts
- coordinate comments, replies, and follow-up content

### Additions

- campaign planner
- content calendar generator
- social sequence engine
- thread expansion builder

## Phase 5 — Maturity and distribution

### Goals

- turn the package into a product, not just a repo
- create onboarding, dataset management, and user dashboards

### Additions

- onboarding flow
- account-level memory settings
- dashboard with engagement insights
- export and revision history

## Best strategic direction

The best path is not “more skills.”

The best path is:

- memory
- verification
- learning
- personal brand velocity

In other words: the repo should become a system that helps a person become more recognizable, more credible, and more consistent online.

## Long-term product vision

A neurodivergent-first LinkedIn growth operating system that:

- learns your actual voice
- expands your strongest ideas
- spots weak or risky positioning
- turns engagement data into better strategy
- helps founders and builders stay visible without sounding fake

That is the true category win.
