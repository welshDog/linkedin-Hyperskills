# 90-day MVP build roadmap

## Phase 1: Weeks 1-4 — foundation and onboarding

### Deliverables
- auth and signup flow
- user dashboard shell
- brand profile creation
- sample post upload
- voice extraction draft
- save and retrieve profile logic

### Outcome
Users can create a profile and feed the product their voice data.

## Phase 2: Weeks 5-7 — generation and scoring

### Deliverables
- generation API
- multiple drafts per brief
- content scoring service
- claim safety checks
- review screen with score breakdown

### Outcome
Users can generate a first draft and receive guidance before approval.

## Phase 3: Weeks 8-9 — approval and publish flow

### Deliverables
- draft approval/reject UI
- assign status to posts
- schedule or publish flow
- fallback copy-paste publishing flow
- saved post history

### Outcome
Users can move from draft to publish with minimal friction.

## Phase 4: Week 10 — beta polish and launch readiness

### Deliverables
- fix top P1 bugs
- finalize onboarding and help copy
- monitor generation quality and safety behavior
- setup beta feedback loop
- prepare launch materials

### Outcome
The product is ready for a focused beta launch.

## Meaningful milestones

By the end of 90 days, the product should have:

- working auth
- working profile build
- generation from user topic
- safety and score layer
- publish or schedule flow
- clean beta-ready UX

If that works, the product has traction potential.

## Scope discipline

Do not build:
- analytics dashboards before beta
- team features before demand
- advanced image generation
- campaign orchestration
- white-label features

Focus only on the wedge.
