# MVP roadmap

## MVP 1 — Brand profile and draft scoring

Build the first working system around:

- brand memory profile
- draft scoring
- claim-risk flags
- approval workflow

### Deliverables

- voice profile model
- scoring engine
- risk flags
- simple UI or CLI review

## MVP 2 — Analytics loop

Add the ability to:

- log content outcomes
- compare post types
- find signal patterns
- tune future recommendations

### Deliverables

- analytics store
- hook taxonomy
- post result tracking

## MVP 3 — Sequence generation

Move from single posts to campaigns:

- follow-up posts
- supporting comments
- series generation
- CTA variations

### Deliverables

- sequence planner
- campaign generation engine

## MVP 4 — Founder and operator playbooks

Add modes for:

- founders
- agencies
- operators
- B2B builders
- personal brands

### Deliverables

- mode-specific templates
- strategic writing prompts
- proof-driven messaging

## MVP 5 — Publisher integration

Connect the content system to a scheduling or publishing layer.

### Deliverables

- draft approval
- publishing orchestrator
- campaign execution

## Final product goal

By the end, this becomes a content intelligence engine for strategic personal branding on LinkedIn.

That is bigger and more valuable than “just another AI writing tool.”
